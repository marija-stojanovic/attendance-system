# Infrastruktura

Mjesto za buduće konfiguracije servisa. Planirani su root `compose.yaml`, Dockerfile za svaku aplikaciju, PostgreSQL, Eureka i eksterna konfiguracija.

Dodati healthcheck provjere i ponašanje pri nedostupnim zavisnostima. Demo mora biti pokretljiv jednom komandom. Stvarni institucionalni kredencijali ostaju izvan Gita. Eventualni Keycloak sa testnim nalozima treba razlikovati od institucionalne autentifikacije.
