# Zajednički rad

Za svaki zadatak napraviti granu i pull request koji pregleda druga osoba.

Sa sačuvanim prethodnim izmjenama:

```bash
git switch main
git pull --ff-only
git switch -c codex/course-import
```

Naziv grane prilagoditi zadatku. Prije commita pregledati `git status` i `git diff --cached`.
